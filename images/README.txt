ABOUT PORTRAIT IMAGE
====================

The "About Me" section (#about) shows a tall celestial portrait card on the
left. To use your own image:

1. Put your image file in THIS folder (current-site/Lia-Website/images/).
2. Name it exactly:   about-portrait.jpg
   A vertical / portrait-orientation image works best — roughly 3:4,
   e.g. 900x1200px or larger. It is shown with object-fit: cover.

Then reload index.html.

Prefer a different filename or a .png? Either tell me and I'll update the one
<img src="..."> line, or edit it yourself:
   current-site/Lia-Website/index.html  ->  search for  images/about-portrait.jpg

If no image is present, the card falls back to a starfield + moon placeholder,
so the layout still looks intentional.
